# Published Reference Results

This directory contains the reference results reported in the published manuscript:

**Quantifying Behavioral Contributions to Diabetes Risk Using an Explainable Multiclass Machine Learning Framework with BRFSS 2024**

These results represent the final research analysis and are intended for comparison with independently reproduced outputs.

## Directory Structure

- `results/reference/` — Verified numerical results from the accepted manuscript.
- `results/tables/` — Automatically generated outputs from executing the reproducibility scripts.

## Reproducibility

The scripts in `src/` reproduce the study's analytical workflow using BRFSS 2024 data. Minor numerical differences may occur between newly generated results and the manuscript's reference values.

Reference results must not be overwritten by script execution. The original manuscript remains the authoritative source for the reported findings.
